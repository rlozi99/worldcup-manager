# 월드컵 매니저

온라인 팬페이지 월드컵(토너먼트 투표) 진행을 자동화하는 데스크톱 앱입니다.
대진표 생성, 제목 생성, 브라우저 자동 업로드, 댓글 자동 수집, 투표 집계까지 한 앱에서 처리합니다.

## 기능

- ⚙️ **설정**: 작업 폴더 / 대회명 / 라벨을 앱 안에서 관리
- 📝 **제목 생성**: 라운드별 게시글 제목 자동 생성
- 🏆 **대진표 만들기**: 원본 사진 셔플/조편성, 사진 클릭으로 승자 선택 → 다음 라운드 생성, 썸네일(GIF→JPG) 자동 생성
- 📤 **제목/사진 자동 업로드**: 브라우저에 제목+이미지 자동 붙여넣기 (마우스 좌표 자동화)
- 💬 **댓글 자동 수집**: 각 조 게시글 댓글을 자동으로 복사해서 저장
- 📊 **투표 집계**: 저장된 댓글에서 득표수 집계 및 승자 판정

## 설치

```bash
pip install PySide6 Pillow pyautogui pyperclip
```

## 실행

```bash
python main_app.py
```

## 참고

- `settings.json`, `position_cache.json`은 실행하면 자동으로 생성되는 개인 설정 파일이라 깃 저장소에는 포함하지 않았습니다 (`.gitignore` 참고).
- 좌표 자동화(제목/사진 자동 업로드, 댓글 자동 수집) 기능은 Windows + Brave 브라우저 환경을 기준으로 만들어졌습니다.
